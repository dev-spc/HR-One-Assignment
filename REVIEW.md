# REVIEW.md

Defects found in the starter `app/main.py`. The starter was rewritten around small classes (`Clock`, `Shift`, `Rules`,
`Store`, `Attendance`, `Analytics`), so "how fixed" names the new home of each rule.

## Looked at and decided it was not a defect

* `load_dotenv()` before `os.getenv(...)`: `python-dotenv` does not override variables that already exist, so the grader's real environment wins. Kept.
* Default values `mongodb://localhost:27017` / `attendance_db`: a local fallback, not hard-coded production details. Kept.
* `MongoClient` created at import time: PyMongo connects lazily and the client is thread-safe, so this is fine with FastAPI's threadpool for `def` endpoints. Kept (moved into `Store`).
* `doc.pop("_id", None)` after `insert_one`: `insert_one` mutates the dict and adds `_id`, so removing it before returning is right. Replaced by the serializer, same intent.
* `status_code=201` on both creates: correct per contract.
* `if department:` in `list_employees` makes `?department=` mean "no filter". I changed it to `is not None`, so an empty
  string is an exact (empty) match, which is what "exact, case-sensitive match" suggests. A judgment call, not a defect.
